An agent is your own AI assistant or bot, for example Claude Desktop, Cursor or a script of yours. Add it here and it gets a key: with that key it pays through this wallet, within your rules.

One agent can use every service, including all four Fizzl services below. You don't add services as agents. More agents only help to keep assistants apart, so you can pause or remove one on its own.
