How your agent uses it

  • With the Fizzl connector (ChatGPT, Claude, Grok): nothing to do. It sends your pass to Fizzl's services itself, and a call your vault can pay comes back right away, with nothing to sign.
  • With the Fizzl MCP server (presign-guard-wallet-mcp): its free checks send the pass itself.
  • Any other client: copy the signed proof from your dashboard (or have the agent fetch it with its key: GET https://wallet.fizzl.eu/v1/pass) and send it as the header X-Fizzl-Pass to Fizzl's services. A paid call with that header and no payment is paid from the vault when it holds enough (the answer then has x-fizzl-vault: paid). The balance: GET https://x402-doctor.fizzl.eu/api/v1/vault with the same header.

The proof works like a key to your vault: send it only to Fizzl's services (x402-doctor.fizzl.eu, presign-guard.fizzl.eu, ichimoku-signal.fizzl.eu, buy.fizzl.eu) and to partners you trust.

For sellers: give pass holders your own terms

Any x402 seller can recognise a pass and decide what it is worth: a lower price, a higher free limit, faster answers. Fizzl doesn't take a cut and doesn't need to be asked.

Check a wallet, free, from a server or a browser (CORS). It tells you the tier and the end date, never whose pass it is:

GET https://wallet.fizzl.eu/v1/pass/status?wallet=0x…
{ "wallet": "0x…", "pass": { "tier": "bronze", "name": "Fizzl Pass Bronze", "until": 1793000000000 } }

Or verify the proof offline, when an agent sends you its X-Fizzl-Pass header: fzp1.<claims>.<signature>, signed with Ed25519. The public key is at /.well-known/fizzl-pass.json (fetch it once, keep it a few hours). The claims: tier, until (ms), wallets (the owner's and the agents'), iss, iat and kid. In Node:

import { createPublicKey, verify } from "node:crypto";

const { keys } = await (await fetch("https://wallet.fizzl.eu/.well-known/fizzl-pass.json")).json();

// The claims of a valid, current pass; null otherwise.
function checkPass(token) {
  const [v, body, sig] = String(token ?? "").split(".");
  if (v !== "fzp1" || !body || !sig) return null;
  const claims = JSON.parse(Buffer.from(body, "base64url"));
  const jwk = keys.find((k) => k.kid === claims.kid);
  if (!jwk) return null;
  const key = createPublicKey({ key: { kty: "OKP", crv: "Ed25519", x: jwk.x }, format: "jwk" });
  const ok = verify(null, Buffer.from(`${v}.${body}`), key, Buffer.from(sig, "base64url"));
  return ok && claims.until > Date.now() ? claims : null;
}

To check that the proof belongs to the wallet that pays you, compare the payer with claims.wallets. Fizzl credit can't be spent at partners: what you give pass holders is yours.
